# Changelog

All notable changes to the MEL agent-team framework are recorded here.

Format: Keep a Changelog. Versioning: SemVer.

## [0.1.0] — 2026-11-11

### Added

- Initial public framework template for Monitoring, Evaluation & Learning (MEL) agent teams.
- Topic-neutral `template/` tree for copying into instance repos.
- Seven base role definitions and thin bootstrap prompts.
- Team process, board protocol, ownership rules, and human-gate guidance.
- Python scripts for fetch, transform, dashboard build, and repo validation.
- GitHub Actions workflows for validate, Pages deploy, and optional scheduled fetch.
- Static dashboard shell for GitHub Pages.
- Instantiation guide, operating guide, design rationale, and Actions primer.
