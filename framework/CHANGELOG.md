# Changelog

All notable changes to the MEL agent-team framework are recorded here.

Format: Keep a Changelog. Versioning: SemVer.

## [0.1.0] — 2026-11-11

### Added

- Initial public GitHub **template** for Monitoring, Evaluation & Learning (MEL) agent teams.
- Repo **root** is the instance skeleton (`team/`, `agents/`, `data/`, `docs/` dashboard, `scripts/`, workflows).
- Framework-only material under `framework/` (README, INSTANTIATE, CHANGELOG, design/ops docs, prompts, tests).
- Seven base role definitions and thin bootstrap prompts (including interactive Lead chat).
- Team process, board protocol (human inbox), ownership rules, Actions-as-mechanical-arm guidance.
- Python scripts for fetch, transform, dashboard build, and repo validation.
- GitHub Actions: validate + Pages + optional fetch; framework pytest job guarded to this repo only.
- Static dashboard shell for GitHub Pages with honest empty/stale state.
